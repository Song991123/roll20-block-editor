# Roll20 Product Reset

Use this skill when the project goal, folder structure, agent ownership, or
current status needs to be reset before more feature work.

## Startup

Read `AGENTS.md`, then `docs/operations/41_product_reset_and_short_term_goals.md`,
`docs/operations/43_agent_context_pack.md`, `docs/qa/31_active_todo.md`, and
`docs/PROJECT_STRUCTURE.md`. Run `git status --short --branch` and the server
hygiene check before starting a server or browser task.

## Operating method

1. Classify each claim as DONE, VERIFY, BLOCKED, or TODO.
2. Choose one bounded track with one owner and one worktree.
3. Read only Tier 1 documents relevant to that track.
4. Use synthetic public-safe fixtures for committed tests.
5. Keep real sheet inputs, screenshots, and generated reports ignored and
   anonymous.
6. Do not mix design, renderer, import/export, and actual Roll20 evidence in
   one unbounded change.
7. Update the shared status documents only through the lead integrator.

## Exit report

Report the branch, commit, changed files, exact checks, evidence tier, and
remaining VERIFY/BLOCKED items. Never convert activation, local smoke, or a
single payload result into a universal or pixel-parity claim.
