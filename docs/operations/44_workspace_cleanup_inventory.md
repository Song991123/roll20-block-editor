# 44. Workspace Cleanup Inventory

Date: 2026-07-18
Status: STAGED CLEANUP COMPLETE - COMPATIBILITY ROOTS PRESERVED

The parent folder contains the active application, source corpora, old
worktrees, experiments, and generated byproducts. This document prevents an
agent from treating every sibling folder as an active product workspace.

## Canonical Active Workspace

| Path | Role | Action |
| --- | --- | --- |
| `web-push-main/` | Active Next/React worktree and integration branch. | Only place for current product edits and integration commits. |
| `web-push-main/docs/` | Hand-authored operating, product, UX, QA, and research documents. | Keep indexed; do not store generated evidence here. |
| `web-push-main/app/`, `components/`, `lib/`, `scripts/` | Product code and repeatable verification scripts. | Current implementation ownership. |
| `web-push-main/test-fixtures/`, `reports/`, `.tmp/` | Ignored local verification spaces. | Use only for ephemeral or anonymous evidence. |

## Protected Or External Material

The source folders listed in `AGENTS.md` are read/copy-only. They must never be
renamed, normalized, edited, deleted, or used as a working tree. Copy only the
minimum input to an ignored fixture path when a test requires it.

The parent-level `sheet/`, `roll20-base/`, `api/`, and `docs/` folders are
reference material. Their ownership and cross-references must be inventoried
before any move.

## Legacy And Experiment Siblings

The following categories are not active product workspaces:

- single-file editor/viewer remnants;
- `web-sfx*`, `_bundle_work`, `samples-*`, and similar experiment copies;
- `web-claude-*` and other worktrees created for parallel agents;
- broken git metadata snapshots and tool-specific caches.

Do not delete or merge these during the product reset. Before archiving one,
run a reference search across scripts, CI, docs, git worktrees, and open
processes. Archive only after the user-visible active path is unaffected and a
recoverable backup exists.

## Generated Byproducts

`.next/`, `out/`, `node_modules/`, `debug.log`, `.tmp/`, caches, and ignored
reports are generated or diagnostic. They are not product source and should
not be described in portfolio or agent handoffs. Server cleanup may stop an
unneeded listener; it must not delete evidence or source by default.

## Safe Cleanup Sequence

1. Inventory references and active git worktrees.
2. Confirm no process, script, CI job, or user workflow depends on the target.
3. Copy/backup before moving anything outside the active worktree.
4. Move one category at a time and update `폴더 안내.md` plus this document.
5. Run server hygiene, lint/build, and the relevant smoke after each move.
6. Commit the inventory and move separately so a move can be reverted without
   mixing it with product code.
